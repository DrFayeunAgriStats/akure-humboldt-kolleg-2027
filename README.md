# Akure Humboldt Kolleg 2027 — AFDS staging showcase

This repository currently hosts the **free, fully sponsored conference interactive HTML showcase** (`index.html`). Event: **22–25 February 2027**, proposed venue **Federal University of Technology, Akure (FUTA)**.

## Important

- This is a **client demonstration**. No real registrations, abstract uploads or reviewer actions are stored by this website.
- Conference details, organisers, venue hall, sponsors and content are subject to approval.
- No payment provider is included: admission is free.
- The fully functional **Next.js + Field-to-Insight Supabase** application is being staged separately. Do not open registration until that app passes end-to-end tests.

## Deploy the present showcase to Vercel

Import this GitHub repository with **Framework Preset: Other**, **Root Directory: `./`**, no custom build command, and click Deploy. Vercel can serve the root `index.html` as a static site.

When deploying the backend application later, replace the static site with the prepared Next.js source, change the Framework Preset to Next.js, add the appropriate environment variables, and perform acceptance tests.
