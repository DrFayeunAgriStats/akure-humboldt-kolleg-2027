# Homepage design concepts (for LOC comparison)

Two directions for the redesigned homepage, kept for the final visual comparison. These are static design concepts: they are **not** part of the application and are not served by it.

| Concept | File | Previews |
|---|---|---|
| **A · Nexus** (provisional preference) | `concept-a-nexus.html` | `previews/a-desktop-fold.jpg`, `a-phone-fold.jpg`, `a-desktop-full.jpg`, `a-phone-full.jpg` |
| **B · Horizon** | `concept-b-horizon.html` | `previews/b-*.jpg` |

Open the HTML files directly in a browser and resize the window to compare desktop and phone layouts. Fonts load from Google Fonts. Concept B uses the project's rainforest artwork as a **marked stand-in** for licensed FUTA/Akure photography.

Both concepts drop the previous rainforest-photo hero, serif headings, green-and-gold palette and "at a glance" panel. Both cut the homepage from about 850 to under 200 visible words, and both place the theme, dates, venue, Register and Submit actions on a phone's opening screen. Copy, dates, logos and key dates are placeholders until approved by the LOC.
